## The entry

> I asked the calendar why it looked so stressed - it said too many dates, not enough time to itself.

99 characters, one line — inside the 140-character gate.

## Run it

```sh
python3 main.py
```

It writes the joke to `/output/entry.txt` and validates it first: a single
non-blank line of 1 to 140 characters.
